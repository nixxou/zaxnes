# Q-011 — Les patterns temporaires du fichier : REQ-E3D-060 et REQ-E3D-065 ne peuvent pas être vrais ensemble

- **Ouvert par** : R3 (côté propre), lot L4a, 2026-10-20
- **Documents concernés** : SPEC-04 REQ-E3D-060 (inscription au chargement) et son critère
  d'acceptation, REQ-E3D-065 (règles de remplacement), REQ-E3D-160 (note : 1 223 patterns
  temporaires intégrés)
- **Classe** : C (contradiction interne entre une exigence P1 et le critère d'acceptation d'une
  autre exigence P1)
- **Priorité** : P1 (décide le contenu du registre au chargement de tout profil)

## Contradiction

REQ-E3D-060 demande d'inscrire au registre « tous les permanents dans l'ordre du fichier, puis
tous les temporaires dans l'ordre du fichier », et son critère d'acceptation est :

> pour chacun des 101 profils de `assets-neutral/profiles`, le nombre de patterns inscrits est
> égal au nombre de patterns permanents plus temporaires du fichier

REQ-E3D-065 demande, de son côté :

> Quand un pattern **temporaire** de clé K est ajouté, le moteur DOIT retirer tout pattern
> temporaire T tel que `Img(K) ⊆ Img(T)`.

Appliquée aux temporaires du fichier, cette règle en retire certains, et le compte du critère de
REQ-E3D-060 n'est plus atteint. Mesure faite côté propre sur les 101 profils :

| Profil | Patterns dans le fichier | Inscrits avec la règle | Écart |
|---|---|---|---|
| Elevator Action | 300 | 297 | 3 patterns temporaires |
| les 100 autres | — | identique | 0 |

« Elevator Action » contient donc trois patterns temporaires dont l'ensemble d'images contient
celui d'un temporaire inscrit après eux. Aucun autre profil intégré n'est concerné, et aucun
profil ne contient deux patterns permanents de même clé (la seconde moitié du critère de
REQ-E3D-060 est, elle, vérifiée : 101 sur 101).

Le texte de REQ-E3D-065 précise « (chargement ou apprentissage) » pour le cas **permanent**
seulement ; le cas temporaire ne dit pas à quel moment il s'applique.

## Choix provisoire

Le chargement d'un profil inscrit les patterns **tels quels**, sans les règles de remplacement ;
celles-ci s'appliquent aux patterns ajoutés **pendant la partie** (apprentissage, REQ-E3D-160 et
REQ-E3D-161), ainsi qu'à la restauration d'un savestate, qui remet le registre dans l'état
enregistré. Les deux critères d'acceptation sont alors vrais en même temps : 101 profils sur 101
inscrivent tous leurs patterns, et le registre reste purgé de ses sous-ensembles temporaires
pendant le jeu.

Argument annexe : la version publique antérieure du moteur (`third_party/3DNes_Engine`,
GPL-3.0) fait exactement cela — `Pattern.AfterDeser()` ajoute le pattern directement à
`PatternManager.patterns` ou `tempPatterns`, sans passer par `PatternManager.Add()`, qui est le
seul endroit où les règles de remplacement sont appliquées.

Références dans le code : `Sen.Engine3D.PatternRegistry.Register` (`// Q-011`) pour le
chargement et la restauration, `PatternRegistry.Add` pour l'apprentissage. Tests :
`CorpusTests.REQ_E3D_060_every_built_in_profile_registers_all_its_patterns` (67 832 patterns et
74 389 objets 3D inscrits, conformes à l'annexe A de SPEC-04B),
`RegistryTests.REQ_E3D_065_*`.

## Question posée à R0

Confirmer que les règles de REQ-E3D-065 ne s'appliquent pas à l'inscription des patterns d'un
fichier, et préciser le texte de REQ-E3D-065 en conséquence (« quand un pattern est ajouté
pendant la partie »). Si c'est au contraire la règle qui prime, corriger le critère
d'acceptation de REQ-E3D-060 (« 100 profils sur 101, Elevator Action perdant 3 patterns
temporaires »).

## Réponse R0 (2026-10-20, normative)
Choix provisoire validé, avec une précision : au **chargement d'un profil**, chaque pattern (permanent ou temporaire) est enregistré tel quel, **sans** appliquer les règles de remplacement de REQ-E3D-065. Seule exception : un pattern égal (au sens de l'égalité de patterns de SPEC-04) à un pattern déjà enregistré dans le même ensemble est ignoré, et le premier est conservé. Les règles de remplacement ne s'appliquent qu'à l'apprentissage en cours de partie. Le critère « 101 sur 101 » de REQ-E3D-060 s'entend donc « tous les patterns non dupliqués ».
