# Q-061 — Quarth absent : comment couvrir l'algorithme MARCHING de REQ-ACC-020

- **Ouvert par** : R4 (vérificateur, côté propre), vérification finale P5r, 2026-10-21
- **Documents concernés** : SPEC-12 REQ-ACC-020 et §2 ; SPEC-04 REQ-E3D-340
- **Classe** : B (jeu de référence indisponible)
- **Priorité** : P1 (REQ-ACC-020 est P1)

## Écart

REQ-ACC-020 liste douze jeux de référence et annote le douzième « Quarth (algorithme
MARCHING) ». Le dossier de l'utilisateur en contient onze ; **Quarth n'y est présent que sous la
forme d'une ROM Game Boy** (`Quarth (USA, Europe).gb`, 64 Kio), que ce cœur ne lit pas et n'a
pas à lire (SPEC-02 §1, hors périmètre). Le profil `Quarth.bytes` (id 93) est bien dans
`assets-neutral/profiles/`, mais sans ROM il ne peut pas être exercé.

La mention « algorithme MARCHING » désigne la raison pour laquelle ce jeu figure dans la liste,
et non une propriété du jeu : d'après REQ-E3D-340 l'algorithme de maillage est un **réglage
global de l'utilisateur** (défaut GREEDY), jamais pris du profil, plus une valeur par instance
`rm`. Rien n'attache MARCHING à Quarth autrement que par l'usage.

## Choix provisoire

La partie « jeu » de la ligne Quarth est portée **en attente de ROM** et comptée comme justifiée
par REQ-ACC-050 ; la partie « algorithme MARCHING » est couverte par ailleurs, sur des jeux de
référence qui sont présents, avec le réglage global forcé à MARCHING :

- **Tetris**, **Super Mario Bros.** et **Metroid**, 18 000 frames chacun (cinq minutes) avec
  `RenderAlgorithm = Marching` : 735 210 à 3 401 291 shapes reconnues, 193 à 1 567 objets
  construits par le mailleur marchant, jusqu'à 860 tiles de dessin, aucun plantage.
- Voir `tests/Acceptance/FinalRomTests.cs`,
  `A_reference_game_plays_five_minutes_with_the_marching_algorithm`.

REQ-ACC-020 est donc jugée **CONFORME** sur les onze jeux disponibles plus cette couverture de
l'algorithme, avec la ligne Quarth signalée comme justifiée.

## Question posée à R0

1. Confirmer que forcer MARCHING sur un jeu de référence présent couvre la raison pour laquelle
   Quarth figure dans la liste, ou exiger la ROM NES de Quarth.
2. Le cas échéant, remplacer dans REQ-ACC-020 l'annotation « Quarth (algorithme MARCHING) » par
   une exigence explicite : « au moins un jeu de référence joué cinq minutes avec le réglage
   global MARCHING ».

## Réponse R0 (2026-10-21, normative)
Validé : faute de ROM NES de Quarth, la part MARCHING de REQ-ACC-020 est couverte par des jeux de référence rendus avec l'algorithme MARCHING forcé en réglage global (Tetris, SMB, Metroid). Quarth reste à vérifier si une ROM Famicom devient disponible.
