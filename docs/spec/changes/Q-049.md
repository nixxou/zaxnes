# Q-049 — Raccourcis fixes et touches de la table §4.2 : REQ-INP-106 contre AMD-010 REQ-UI-204

Ouvert par : R4 (vérificateur indépendant, round 1, partie C), 2026-10-21
Exigences : SPEC-08 REQ-INP-106, AMD-010 REQ-UI-204 (corrigée par AMD-013, Q-030)

## Contradiction

REQ-INP-106 : « Une implémentation PEUT ajouter des raccourcis fixes (plein écran, par exemple),
à condition qu'ils **n'utilisent aucune touche de la table §4.2**. » Critère : « aucune touche
absente de la table §4.2 n'a d'effet en jeu avec la configuration par défaut. »

AMD-010 REQ-UI-204 impose pourtant des raccourcis de menu qui réutilisent quatre touches de la
table §4.2 :

| Raccourci exigé par REQ-UI-204 | Touche de §4.2 réutilisée |
|---|---|
| `Ctrl+Fn` (charger l'état n, n = 1…10) | `F5` à `F10` = RotLeft…ZoomOut |
| `Maj+Fn` (sauvegarder l'état n) | idem |
| `Alt+Entrée` (plein écran) | `Entrée` = Start |
| `Ctrl+,` (Options) | `,` = RollBack |

Lue à la lettre, REQ-INP-106 rend REQ-UI-204 inapplicable. Les deux textes ne se contredisent
plus si « utiliser une touche de la table §4.2 » signifie « l'utiliser **seule**, sans
modificateur » — ce que confirme la phrase de REQ-UI-204 « sans conflit avec les touches de jeu
par défaut » et la réponse Q-030 (AMD-013), qui déplace précisément le chargement d'état de `Fn`
seul vers `Ctrl+Fn` pour éviter le conflit.

## Choix provisoire du vérificateur

REQ-INP-106 est lue comme portant sur les raccourcis **sans modificateur** : un raccourci fixe
qui exige Ctrl, Maj ou Alt n'« utilise » pas la touche de jeu au sens de l'exigence, puisque la
touche nue continue de produire son action.

Vérifié dans cette lecture : les seuls raccourcis fixes sans modificateur sont `P`, `F11` et
`F12`, aucun des trois n'étant dans la table §4.2.

Verdict retenu : REQ-INP-106 **CONFORME**.

## Correction suggérée

Ajouter à REQ-INP-106 : « …aucune touche de la table §4.2 **employée seule** ; une combinaison
avec Ctrl, Maj ou Alt est permise, la touche nue gardant son action de jeu. »

## Réponse R0 (2026-10-21, normative)
AMD-010 et AMD-013 priment (décision postérieure) : raccourcis de menu de REQ-UI-204, chargement d'état par Ctrl+Fn ; les touches nues de la table §4.2 de SPEC-08 gardent leur rôle de jeu et de caméra.
