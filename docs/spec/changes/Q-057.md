# Q-057 — Le message de suppression d'un slot est écrit `<n>` par SPEC-10 et `<id>` par SPEC-09, et le slot rapide n'a pas de numéro

- **Ouvert par** : R4 (vérificateur indépendant, côté propre), re-vérification ciblée du round 1, 2026-10-21
- **Documents concernés** : SPEC-10 REQ-UI-052 ; SPEC-09 REQ-PERS-054, REQ-PERS-050 ; AMD-010 REQ-UI-208
- **Classe** : deux rédactions du même texte, et un cas non couvert
- **Priorité** : P2 (REQ-UI-052 est P2, REQ-PERS-054 est P1)

## L'ambiguïté

Les deux documents fixent le **texte exact** de la même boîte de confirmation, mais pas avec le
même emplacement variable :

- SPEC-10 REQ-UI-052 : « message : `Do you want to delete the slot <n> ?` » — `n` est un
  **numéro** ;
- SPEC-09 REQ-PERS-054 : « après confirmation « `Do you want to delete the slot <id> ?` » » —
  `id` est l'**identifiant** du slot.

Pour les 36 slots numérotés, les deux coïncident : REQ-PERS-050 donne aux slots numérotés les
identifiants `1` à `36`, qui sont leurs numéros écrits. Mais le **slot rapide** a l'identifiant
`quick` et n'a pas de numéro. Or :

- REQ-PERS-042 exige d'effacer « tous les slots associés à ce jeu (**y compris le slot rapide**) » ;
- AMD-010 REQ-UI-208 expose le slot rapide dans les menus au même titre que les dix slots
  numérotés ;
- REQ-UI-052 ne parle que de « la tuile sélectionnée d'un slot non vide, dans LOAD comme dans
  SAVE », sans exclure le slot rapide.

Il n'existe donc pas de rédaction du message pour le slot rapide : `<n>` n'a pas de valeur, et
`<id>` en a une (`quick`) qui n'est pas un numéro.

## Choix provisoire retenu

La lecture `<id>` de SPEC-09 est appliquée, puisqu'elle est définie pour les 37 slots et qu'elle
donne exactement le texte de SPEC-10 pour les 36 slots numérotés. La boîte du slot rapide affiche
donc « `Do you want to delete the slot quick ?` ». REQ-UI-052 et REQ-PERS-054 sont jugées
**CONFORME** sur cette base : le texte du cas que les deux documents couvrent est exact au
caractère près, espace avant le point d'interrogation compris.

## Question posée à R0

1. Confirmer que `<id>` fait foi et que le slot rapide affiche son identifiant, ou
2. fixer un libellé propre au slot rapide (par exemple « `Do you want to delete the quick slot ?` »
   ou le libellé affiché « État rapide »), auquel cas REQ-UI-052 et REQ-PERS-054 doivent l'écrire.

Accessoirement : aligner les deux documents sur un seul emplacement variable, `<id>`.

## Réponse R0 (2026-10-21, normative)
Lecture du vérificateur validée ; aucun verdict ne change. À réexaminer si le round 2 révèle un écart observable.
