# Q-053 — Critère de REQ-INP-123 non recalculé en v1.1 (visée Zapper libretro)

Ouvert par : R4 (vérificateur indépendant, round 1, partie C), 2026-10-21
Exigences : SPEC-08 REQ-INP-123 (P2), REQ-INP-063 (P1), SPEC-08 §5.3

## Erreur de spécification

REQ-INP-123 demande que la position fournie par l'hôte libretro soit convertie « par le **même
lancer de rayon** que REQ-INP-063 », puis donne ce critère :

> sous RetroArch, viser le point de scène `C = (128, 120, 0)` en vue par défaut → **(128, 120)**
> ±1 ; viser le centre de l'image NES → **(128, 112)** ±1 (même relation que REQ-INP-063).

Or la relation de REQ-INP-063, telle que l'historique de SPEC-08 la fixe en v1.1
(« visée du Zapper alignée sur DEC-08-4 … `py = tronc(248 − y)` … vecteurs §5.3 recalculés »),
donne pour les deux mêmes points :

| Point de scène visé | REQ-INP-063 et §5.3 (v1.1) | Critère de REQ-INP-123 |
|---|---|---|
| `C = (128, 120)` | **(128, 128)** | (128, 120) |
| centre de l'image NES `(128, 128)` | **(128, 120)** | (128, 112) |

Les deux valeurs de REQ-INP-123 sont exactement celles de la relation **antérieure**
(`py = tronc(240 − y)`, 1.1-draft), décalées de 8 lignes. Le critère n'a pas été recalculé quand
la ligne N-1 de `R2-review-v1.1` a corrigé REQ-INP-063.

Les deux exigences ne peuvent pas être satisfaites ensemble : « la même relation que
REQ-INP-063 » et les nombres écrits se contredisent.

## Choix provisoire du vérificateur

La phrase normative (« le même lancer de rayon que REQ-INP-063 », « même relation que
REQ-INP-063 ») fait foi ; les deux nombres du critère sont tenus pour périmés. L'implémentation
n'a qu'une seule fonction de visée (`ZapperAim`), partagée par l'hôte desktop et par un futur
hôte libretro, ce qui satisfait la règle par construction.

Verdict retenu : REQ-INP-123 **CONFORME** sur la règle, le frontend libretro restant la cible P7.

## Correction suggérée

Remplacer les deux valeurs du critère de REQ-INP-123 par celles de §5.3 : `C = (128, 120, 0)` →
(128, 128) ±1 ; centre de l'image NES → (128, 120) ±1.

## Réponse R0 (2026-10-21, normative)
Le critère de REQ-INP-123 suit la relation amendée de REQ-INP-063 (DEC-08-4 : pixel affiché, `py = tronc(248 − (y − Oy)/e)`) ; les valeurs attendues sont recalculées en conséquence.
