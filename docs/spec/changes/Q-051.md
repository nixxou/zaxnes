# Q-051 — Filtre `.7z` du choix de ROM : REQ-UI-036 contre AMD-010 REQ-UI-201 et AMD-013

Ouvert par : R4 (vérificateur indépendant, round 1, partie C), 2026-10-21
Exigences : SPEC-10 REQ-UI-036 (P1), SPEC-10 §4 (table des filtres), AMD-010 REQ-UI-201,
AMD-013 (Q-028), SPEC-07 REQ-LOOP-023

## Contradiction

REQ-UI-036 (P1) : « Le choix de ROM DOIT ouvrir le navigateur de fichiers en mode ouverture,
titré `Select ROM`, filtré sur les extensions `nes`, `zip` et **`7z`**, avec la recherche
active. » La table §4 répète `nes`, `zip`, `7z`.

AMD-010 REQ-UI-201 réécrit la même fonction : « boîte de dialogue de fichiers (filtres `.nes`,
`.zip` **si pris en charge par SPEC-07**, « Tous les fichiers »), mémorisation du dernier
dossier ». AMD-013 (Q-028) tranche que `.7z` n'est **pas** pris en charge : un tel fichier est
refusé avec `Uncompression is not successful`, faute de décodeur autorisé.

Proposer `7z` dans le filtre revient donc à proposer une extension dont le seul effet possible
est un message d'erreur ; ne pas la proposer s'écarte du texte littéral de REQ-UI-036.

## Choix provisoire du vérificateur

AMD-010 REQ-UI-201 est postérieure et redéfinit explicitement les filtres de cette boîte de
dialogue ; AMD-013 ferme la question du décodeur. Le filtre retenu est donc
`nes`, `zip` + « Tous les fichiers », ce dernier laissant choisir un `.7z` et produire le message
documenté. Le titre `Select ROM` relève de la présentation, rendue informative par AMD-010 §1.

Verdict retenu : REQ-UI-036 **CONFORME** (par REQ-UI-201), avec la note ci-dessus.

## Correction suggérée

Ajouter une ligne à AMD-010 §4 : « REQ-UI-036 : le filtre `7z` est retiré (AMD-013, Q-028) ; la
table des filtres de SPEC-10 §4 est remplacée par celle de REQ-UI-201. »

## Réponse R0 (2026-10-21, normative)
Le filtre du choix de ROM propose `.nes`, `.zip` et « Tous les fichiers » ; `.7z` n'est pas proposé (pas de décodeur, AMD-013).
