# Q-043 — REQ-ACC-011 : la « frame de test synthétique » n'est définie nulle part

- Lot : vérification de round 1, partie A
- Rôle : R4 (vérificateur indépendant, côté propre)
- Date : 2026-10-21
- Documents concernés : SPEC-12 REQ-ACC-011 ; SPEC-04 §5 (vecteurs TV-E3D) ; SPEC-05 (API Lua)

## Ambiguïté

REQ-ACC-011 exige :

> Pour chacun des 89 profils qui contiennent des scripts, l'exécution des hooks `Start`, puis de
> 600 frames d'`Update`, `UpdateS` et `LateUpdate`, puis de `End`, **sur une frame de test
> synthétique**, NE DOIT produire aucune erreur Lua due à un membre d'API manquant.
> — Critère : test automatisé ; les erreurs dues aux données de la frame synthétique sont
> tolérées si elles sont documentées.

Deux éléments manquent pour que le test soit reproductible :

1. **Le contenu de la frame synthétique.** Rien n'en est dit : ni le nombre de tiles, ni la
   présence de sprites, ni la palette, ni les masques. Or le contenu décide de ce que les scripts
   rencontrent : une frame vide n'appelle jamais `UpdateS` (aucune instance scriptable) et ne
   peut donc révéler aucun membre d'API manquant, tandis qu'une frame pleine en exerce beaucoup
   plus. Le critère est vérifié ou vide selon ce que le vérificateur choisit.
2. **La frontière entre « erreur due aux données » et « membre d'API manquant ».** Les deux se
   présentent en Lua de la même façon (`attempt to index a nil value`) : un champ absent de
   l'API et un champ existant dont la valeur est nulle parce que la frame ne contient pas
   l'objet attendu donnent le même message. Sans règle de tri, le critère n'est pas décidable.

## Choix provisoire du vérificateur

- Frame synthétique : deux tiles de fond adjacentes d'images distinctes aux cellules (11, 6) et
  (12, 6), plus un sprite en (100, 100), palette du cœur nulle, masques (0, 0). Elle produit au
  moins une shape de fond et une shape de sprite, donc au moins un appel d'`UpdateS` par script
  lié, ce qui est le minimum pour que le critère ait un contenu.
- Tri : toute erreur dont le message contient `attempt to call a nil value` ou
  `attempt to index a nil value` est comptée comme un manque d'API ; les autres (erreurs
  arithmétiques, comparaisons, bornes) sont tolérées comme « dues aux données ».

Avec ce protocole, les 89 profils scriptés passent sans aucune erreur de ces deux familles.

Test : `tests/Acceptance/AcceptanceGateTests.cs`,
`Every_scripted_profile_survives_start_600_updates_and_end`.

2. Donner la règle qui distingue une erreur « due aux données » d'un membre d'API manquant, afin
