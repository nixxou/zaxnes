# The ROM set lot PR-1 measures, one per line: <key> <root> <path relative to that root>.
#
# <root> is `free` for $ZAX_TEST_ROMS (assets-free/test-roms) and `comm` for $ZAX_COMM_ROMS
# (the owner's commercial ROM folder, the one R0's callgrind uses). A line whose file is
# missing is skipped with a warning, so the `free` half runs anywhere.
#
# Why each ROM is here: see docs/progress/PR-1.md, step 1. In short, the CPU read path's cost
# depends on how often a read lands on a PPU register ($2002/$2004/$2007) and on the cartridge,
# so the set spans both axes. The per-ROM register-read counts in the progress file were
# measured over these same 300 frames.

# The two ROMs of PERFORMANCE-HISTORY.md section 7, which is where the -0.86 %/-0.79 % come from.

# Boards: an MMC3 and an MMC5, so the `Board` read that LLVM moves off the path is exercised.
m4       free holy-mapperel/testroms/M4_P128K.nes
mmc5     free nes-test-roms/exram/mmc5exram.nes

# $2002: the case the two ROMs above cannot judge. Duelito spends about a fifth of its read
# cycles on $2002; ppu_vbl_nmi polls it on a bank-switched board.
duelito  free nes-test-roms/other/Duelito.nes
vblnmi   free nes-test-roms/ppu_vbl_nmi/ppu_vbl_nmi.nes

# $2007, and a third register arm ($2004).
